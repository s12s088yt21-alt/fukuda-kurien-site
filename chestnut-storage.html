Storage Guide

栗の保存方法

栗は生ものです。常温に置いたままにせず、 おうちに着いたら早めに冷蔵または冷凍してください。

すぐ食べる分

1週間程度なら冷蔵庫へ。 できればチルド室など、0度に近い場所がおすすめです。

あとで食べる分

長く保存するなら冷凍庫へ。 皮つきのままでも、皮をむいてからでも冷凍できます。

First Check

保存する前に確認

次のような栗は取り除いてください。

  • 穴があいている栗
  • 黒ずみが強い栗
  • やわらかくなっている栗
  • 白っぽい部分がある栗
  • 底の部分がベトベトしている栗
  • 傷みやにおいが気になる栗

汚れが気になる場合は軽く洗い、水気をしっかりふき取ってください。

Refrigerate

1週間程度で食べる場合

  1. 栗の状態を確認します。
  2. ポリエチレン製の袋、または保存袋に入れます。
  3. 袋の口はきつく縛らず、軽く折ります。
  4. 冷蔵庫のチルド室に入れます。
  5. 1週間程度を目安に、できるだけ早く食べます。

袋の中に水気が残ると傷みやすくなります。洗った場合は、水気をよくふいてください。

Freeze

長く保存したい場合

1週間程度で食べきれない分は、早めに冷凍しておくと安心です。

皮つきのまま冷凍

  1. 栗の状態を確認します。
  2. 汚れが気になる場合は軽く洗い、水気をよくふきます。
  3. 冷凍用の袋に入れます。
  4. できるだけ空気を抜き、冷凍庫へ入れます。

使うときは、凍ったままゆでるか、熱湯につけてから皮をむけます。

皮をむいてから冷凍

  1. 外側のかたい鬼皮をむきます。
  2. 茶色い渋皮をしっかり取ります。
  3. 必要なら軽く洗い、水気をよくふきます。
  4. 冷凍用の袋に入れ、空気を抜いて冷凍します。

栗ごはん、甘露煮、ペーストなどに使うときに便利です。

Chestnut Skins

鬼皮と渋皮について

鬼皮

外側のかたい皮です。

渋皮

中についている茶色い薄い皮です。皮をむいた栗として保存する場合は、渋皮まで取ります。

渋皮煮を作る場合は、渋皮を残します。作りたい料理に合わせて処理してください。

How To Use

冷凍した栗の使い方

皮つきの栗

凍ったままゆでるか、熱湯につけてから皮をむいて使えます。

皮をむいた栗

凍ったまま、栗ごはん、煮物、甘露煮などに使えます。

解凍した栗は傷みやすいため、使う分だけ取り出して早めに調理してください。

Questions

よくある質問

今日中に処理できない場合は？

まず冷蔵庫へ入れてください。できればチルド室で保存し、常温に置いたままにしないでください。

皮をむいた栗も冷凍できますか？

できます。渋皮まできれいに取り、冷凍用の袋に入れて空気を抜いてください。

皮つきと皮むき、どちらで冷凍すればいいですか？

手軽に保存したい場合は皮つきのまま、栗ごはんなどにすぐ使いたい場合は皮をむいてからがおすすめです。
